# Formulário de problema (um por problema)

- **Participante:** P1 / P2 / P3 … (sem nome real)
- **Passo da tarefa:** 1–10
- **Severidade**
  - **S1 bloqueante:** impediu de continuar ou perdeu trabalho (travou, projeto não abre, export falha).
  - **S2 grave:** continuou com um desvio difícil (precisou refazer, resultado errado).
  - **S3 menor:** atrapalhou pouco (rótulo confuso, ação lenta, visual estranho).
  - **S4 sugestão.**
- **O que esperava** × **o que aconteceu**
- **Reproduz?** sempre / às vezes / uma vez
- **Captura/tempo no vídeo:** (opcional)
- **Diagnóstico:** cole o JSON de *Copiar diagnóstico* se o app ainda responde.
