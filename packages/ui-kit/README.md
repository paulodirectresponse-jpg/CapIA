# @capia/ui-kit

Design system interno: tokens CSS (claro/escuro), componentes acessíveis (botões, campos numéricos com commit em Enter/blur, selects, sliders, abas, menus, diálogos com foco preso, toasts, divisores redimensionáveis por mouse e teclado) e **ícones próprios** (traços SVG; nenhum ativo de terceiros). Sem lógica de produto e sem dependência do engine. Controles só-ícone exigem `label` (nome acessível + tooltip).
